# 영어 단어 암기 (Business English)

회의·계약·리포트에서 자주 쓰는 비즈니스 영어 표현을 10문제씩 시험 보는 웹 앱입니다.
빌드 도구 없이 HTML / CSS / JavaScript만으로 만들었습니다.

## 기능
- **시험**: 무작위 10문제. 표현과 예문, 그리고 맞는 뜻 또는 다른 표현의 뜻이 제시되고 `맞음` / `틀림`으로 판단합니다.
- **단어 관리**: 표현 추가·편집·삭제, 단어별 정답률, 등록일순 / 정답률순 정렬
- **시험 기록**: 회차별 점수와 정오표

데이터(단어장, 시험 기록)는 각 사용자의 브라우저(localStorage)에 저장됩니다.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `app.js` | 동작 로직 |
| `words.js` | 기본 단어 100개 (`[표현, 뜻, 예문]`) |

## 배포
Firebase Hosting으로 배포합니다. `main` 브랜치에 push하면 GitHub Actions가 자동으로 배포합니다.
